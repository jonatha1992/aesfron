# 00 — Descripción global

## Propósito

El repositorio se presenta como una plataforma web educativa de AESFRON (Asociación de Enfermeros sin Fronteras) para gestionar formación, capacitación e inscripción de profesionales de enfermería en cursos y programas. Fuente: `README.md`.

## Problema

[Inferido] Centralizar la consulta de cursos y la gestión de formación e inscripciones. El README describe ese objetivo general, pero no detalla el proceso actual que se busca reemplazar ni sus usuarios operativos.

## Objetivo general

[Inferido] Ofrecer una aplicación web para consultar cursos, gestionar cuentas y facilitar la inscripción. El README atribuye estas capacidades al producto; su disponibilidad efectiva debe contrastarse con el código.

## Alcance

### Incluido según README (pendiente de confirmación en código)
- Registro, inicio de sesión y perfiles de usuario.
- Roles de administrador y alumno.
- Catálogo de cursos, detalles de unidades y contenidos.
- Inscripción a cursos y pagos en línea mediante MercadoPago.
- Área del alumno «Mis Cursos» y panel administrativo para gestión de contenido.
- Rutas protegidas y autenticación con Firebase Auth.
- Uso de Firebase/Firestore y Firebase Storage.
