# Instrucciones para agentes

Antes de modificar código o comportamiento, consulta [`docs/analisis/README.md`](docs/analisis/README.md) y los documentos funcionales pertinentes.

- La documentación funcional describe lo confirmado por el README y el código; conserva las marcas `[Inferido]` y `[Pendiente]` donde corresponda.
- No presentes como implementada una característica descrita solo por el README; verifica su implementación en el código.
- Respeta los límites funcionales documentados y no agregues integraciones, reglas ni requisitos no respaldados por fuentes del repositorio.
- Si el código y el análisis se contradicen, señala la discrepancia antes de cambiar el comportamiento.
